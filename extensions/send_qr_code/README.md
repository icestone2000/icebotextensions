# send_qr_code — 发送二维码图片

从指定的二维码码库目录中取一张二维码图片，通过微信主动发送给对方，发送成功后自动删除该图片文件。适合收款码、进群码等「一码一发、发完即毁」的场景。

## 类型

A 类 · 大模型工具型

- **工具名**：`send_qr_code`
- **工具类型**：`ToolType.NOTIFICATION`

## 功能

- 从 `directory` 指定的码库目录中挑选一张二维码图片（按文件名排序取第一张），也可通过 `file_name` 指定具体文件
- 支持图片格式：jpg / jpeg / png / gif / bmp / webp / jfif
- 通过当前会话渠道主动发送图片（个人微信 / 企业微信 / 闲鱼）
- **发送成功后自动删除该图片文件**，保证一张码只发一次；删除失败不影响发送结果，会在返回中标注
- 每调用一次发送一张二维码

## 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `directory` | string | 是 | 二维码图片所在目录，例如 `D:/qrcodes/` |
| `file_name` | string | 否 | 指定要发送的文件名，不指定时自动从目录中选一张 |

## 返回

```json
{
  "success": true,
  "message": "二维码已发送并已从码库删除",
  "file": "qr_001.png",
  "channel": "wechat_personal",
  "removed": true
}
```

## 注意

- 工具会**主动向对方发送图片消息**，大模型编排时建议设置 `requires_tool_result: false`
- 码库目录路径由调用方（大模型按提示词）传入，请在提示词中告知大模型实际的码库目录
- 发送成功即删除源文件，请确保目录中的图片有备份或可再生成
