# tire_price_query — 轮胎报价查询

客户在微信 / 企业微信 / 闲鱼里问轮胎价格时，从 Excel 价格表中按 **品牌 + 型号 + 报价类型** 查到报价，按自定义模板排好版直接发给客户。适合轮胎店、汽服门店的报价客服场景。

价格表由业务人员在 Excel 里维护，**改完存盘即生效，不用重启机器人，也不用改代码**。

完整使用说明（含提示词模板、场景演练、常见问题）：[docs/轮胎报价查询工具使用说明.md](../../docs/轮胎报价查询工具使用说明.md)

## 类型

A 类 · 大模型工具型

- **工具名**：`tire_price_query`
- **工具类型**：`ToolType.DATA_QUERY`

## 功能

- 读取 `轮胎型号.xlsx`（列：品牌 / 规格 / 备注 / 若干报价类型列），按品牌 + 型号 + 报价类型取价
- **报价类型完全由表头决定**：除「品牌 / 规格（型号）/ 备注」外的所有列都是报价类型，加列、改名、删列都不用改代码
- 报价类型支持**部分匹配**：「大客户」「大客户价」都能命中「大客户报价」，「客户」会同时命中「大客户报价」「小客户报价」
- 型号 / 品牌支持**通配符** `*` `?`，匹配前统一去空格、全角转半角、转大写；不带通配符时先精确匹配、无结果再按「包含」匹配
- 空价格单元格显示「暂无报价」，文字价（如「面议」）原样输出，完全重复的行自动去重
- `format_template` 是**单条记录**的模板，每条命中结果各渲染一次后换行拼接；渲染后为空的行整行删除，不留空壳文字与标点前的空格
- 结果默认最多 30 条（`max_rows` 可调），超出自动截断并在文末注明总条数
- `send_to_customer` 默认 `true`，渲染后主动发送到当前会话（个人微信 / 企业微信 / 闲鱼）；未命中任何记录时不发消息
- **工具描述动态列出当前表格里真实的报价类型**（`get_description` 运行时读表头），大模型不会去猜不存在的档位
- **后台线程每 30 秒轮询价格表文件变更**，Excel 改动后自动刷新缓存；`unregister` 时自动停止轮询

## 参数

| 参数 | 类型 | 必填 | 中文别名 | 说明 |
|------|------|------|---------|------|
| `model` | string | 是 | 型号 / 规格 | 轮胎型号，如 `205/55R16`；支持通配符 `*` `?` |
| `brand` | string | 否 | 品牌 | 不填 = 返回所有品牌 |
| `quote_type` | string | 否 | 报价类型 | 取值以表头为准；可只写一部分；不填 = 返回所有报价类型 |
| `format_template` | string | 发送时必填 | 格式定义 / 格式 | 单条记录的排版模板，默认 `[品牌] [型号] [备注] [报价类型]：[价格]` |
| `max_rows` | integer | 否 | 最大条数 | 最多返回多少条，默认 30 |
| `price_table_filename` | string | 否 | 价格表文件名 | 用别的价格表时填，如 `轮胎型号_华东.xlsx` |
| `send_to_customer` | boolean | 否 | — | 默认 `true`；填 `false` 只返回 JSON |
| `recipient_id` | string | 否 | — | 覆盖当前会话接收方，一般不用 |

中文别名的意思是：大模型写成 `{"型号": "205/55R16"}` 也能识别。

## 模板占位符

`[序号]` `[品牌]` `[型号]`（`[规格]` 同义） `[备注]` `[报价类型]` `[价格]`

例：`[品牌] [型号] [备注] [报价类型]：[价格]元` →

```text
马牌 205/55R16 A类报价：520元
马牌 205/55R16 防爆胎 A类报价：780元
```

> ⚠️ 单位不要写在 `[价格]` 外面：空价格会渲染成「暂无报价元」。要么模板不带单位，要么让业务在 Excel 单元格里连单位一起填。

## 数据文件

`轮胎型号.xlsx`（取第一个工作表）放在扩展数据根目录（开发环境为 `backend/`，打包环境为 exe 同目录），**不在扩展目录内**。

表结构：

| 品牌 | 规格 | 备注 | A类报价 | B类报价 | C类报价 |
|------|------|------|--------|--------|--------|
| 马牌 | 205/55R16 |  | 520 | 570 | 620 |
| 马牌 | 205/55R16 | 防爆胎 | 780 | 850 | 930 |
| 普利司通 | 235/60R18 | 特殊花纹 | 面议 | 面议 | 面议 |

- 「品牌」「规格」必须有（「规格」也可写成「型号」），「备注」可选
- 其余列名即报价类型名，至少一列
- 规格为空的行会被忽略

本目录附带两份表：

| 文件 | 用途 |
|------|------|
| `轮胎型号.xlsx` | **价格表模板**：446 行常见品牌 + 规格已填好，报价列全空，业务人员照着填价即可。复制到扩展数据根目录直接用 |
| `轮胎型号_测试.xlsx` | **示例与功能验证表**：5 个品牌 40 行，价格已填好，覆盖同型号不同备注、重复行去重、空价格、文字价、`(POR)` 后缀通配符等情况。复制到扩展数据根目录后，调用时 `price_table_filename` 填 `轮胎型号_测试.xlsx` 即可，不影响正式价格表 |

模板里的报价列名（`A类报价 / B类报价 / C类报价`）只是默认叫法，可以直接改成「大客户报价 / 小客户报价 / 批发价」等业务实际使用的名字，也可以增删列——改完存盘 30 秒内自动生效。

## 注意

- 工具默认主动发消息，大模型编排时建议设置 `requires_tool_result: false`，并且 `reply_content` 里不要重复价格，否则客户会收到两遍报价
- `model` 是必填参数，提示词里要写明「客户没给型号时先追问，不要调用工具」
- 未命中任何记录时不发消息，此时客户只会收到引导语——价格表未填齐的阶段，建议改用 `send_to_customer=false` + `requires_tool_result: true` 的「模型转述」模式
- **按客户等级自动选档位**：系统会把「用户标签 / 用户备注」注入大模型上下文，在提示词里写清「标签 → 报价类型」的映射，模型每次调用工具就会自己挑对档位（VIP → A类、老客户 → B类…），无需给不同等级的客户配不同聊天配置。注意标签只有个人微信 3.9 会注入，企业微信 / 闲鱼要改用客户备注，且提示词必须约束模型不要把档位名告诉客户——详见使用说明 [4.3 节](../../docs/轮胎报价查询工具使用说明.md)
