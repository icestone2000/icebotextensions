# 智能微信客服机器人系统 - 完整功能列表


## 一、系统概述

本系统是一个智能微信客服机器人系统，提供：

- **多端客服**：个人微信、企业微信（iPad 第三方）、闲鱼客服
- **智能回复**：关键词、常见问题（FAQ）、大模型（多厂商 LLM）、工具调用
- **运营能力**：聊天配置管理、定时推送、统一群发、订单与客户管理
- **管理后台**：Vue 单页管理端，按权限展示菜单

## 三、认证与用户管理

- **登录 / 登出**：账号密码登录，登出
- **个人资料**：查看与修改个人信息、修改密码
- **用户管理**（后台）：用户列表、创建/编辑/删除用户、重置密码、状态与角色、批量操作、统计与活动
- **权限**：基于角色的访问控制（RBAC），按功能权限控制菜单与接口（如 `wechat:read`、`faq:read`、`order:read`、`system:admin` 等）

---

## 四、智能客服配置

与微信、企业微信、闲鱼**共用**同一套数据（除各端按群/宝贝的开关与提示词外）。

- **常见问题与回答（FAQ）**
  - 维护常见问题与标准答案
  - 支持搜索、匹配测试、命中统计
- **关键词触发回复**
  - 关键词与回复内容配置
  - 支持精确/包含等匹配方式
  - 关键词匹配测试
- **商品信息库**
  - 商品信息的增删改查与搜索
  - 供大模型回复时参考
- **多轮对话配置**
  - 多轮对话流程配置，用于复杂问答场景

**回复优先级（通用）**：关键词 → 常见问题（FAQ）→ 大模型（若开启）。

---

## 五、聊天配置管理

- **群列表与绑定**：群组列表、与微信/企业微信等绑定关系
- **群规则配置**：规则的新增/编辑/删除、优先级、触发条件与动作
- **群组详情与编辑**：单个群组详情、成员、规则、策略、配置编辑
- **群组策略**：运营策略配置与执行（如参与度、内容推广、成员增长等）
- **群组统计**：群组维度统计数据（部分版本）

---

## 六、微信管理（个人微信）

- **连接与状态**：连接/断开微信、状态查询
- **消息管理**：消息列表、搜索、发送/批量发送
- **好友管理**：好友列表与基础操作
- **聊天配置管理**：微信群组列表与操作
- **自动添加好友**：自动通过好友、欢迎语等配置
- **消息群发**：选择目标（群/好友），群发文本/图片/文件等
- **顺序定时群发（滴灌式）**：按随机间隔逐个私聊发送；可配置发送成功后打微信标签，并同步到本地会话目录（与「从微信导入」、按标签筛选一致）
- **系统配置管理**：人工接管命令、发送间隔、文件保存等
- **文件上传管理**：上传与管理供消息/欢迎词引用的文件

---

## 七、企业微信管理（第三方 iPad 设备）

- **iPad 设备管理**
  - 添加设备（授权码、设备名称）
  - 服务器地址、回调地址（需公网可访问）
  - 设备列表、详情、登录（扫码）/ 退出、更新授权码
- **系统配置管理**
  - 工具调用开关、人工接管命令及开关/开启提示
  - 消息发送间隔、延时范围
  - 图片/文件是否保存及保存路径
- **账号配置**
  - 企业微信账号的新建/编辑（名称、昵称、描述等）
  - 自动回复、工作时间
  - 好友自动通过、好友欢迎语（多条）、自动拉群（群名模板、拉人选择）
- **消息管理**：按企业微信配置筛选的收发消息记录
- **企业微信群发**：选择企业微信配置与目标（群/联系人/标签），定时或立即发送，支持文本/图片/文件/视频等
- **聊天配置管理**：企业微信群组与要服务的群/联系人绑定
- **文件上传管理**：与企业微信消息、欢迎词共用的文件管理

---

## 八、闲鱼客服管理

- **账号配置**
  - 闲鱼账号配置的新建/编辑
  - 启动/停止会话（浏览器登录闲鱼）
  - 宝贝消息过滤：全部回复 / 白名单宝贝 / 黑名单宝贝
- **宝贝聊天配置**
  - 按「闲鱼账号 + 宝贝」配置
  - 开关：自动回复、关键词检测、常用问答回复、大模型智能回复
  - 提示词、历史条数等
  - 未配置宝贝使用默认闲鱼回复配置
- **消息管理**：闲鱼账号的收发消息记录与筛选
- **系统配置管理**：工具调用、人工接管命令与提示、发送间隔、文件保存等（闲鱼全局）

回复数据来源与微信共用：关键词、常见问题、大模型（按宝贝开关）。

---

## 九、大模型与智能回复

- **大模型配置管理**
  - 多厂商接入（如 OpenAI、DeepSeek、通义千问、智谱等）
  - API 配置、模型选择、默认模型
  - 提示词模板管理
- **Fallback 阈值与开关**：主模型失败时的降级策略与开关
- **智能回复流程**
  - 关键词 → FAQ → 大模型（可配置是否启用）
  - 结合群组/宝贝的提示词、知识库、常见问题与商品信息、近期聊天记录
- **工具调用**
  - AI 可调用的工具注册与执行
  - 工具列表与单工具信息查询接口
- **智能回复测试**：按群组/配置测试单条消息的回复结果

---

## 十、定时推送与群发

- **定时推送设置**
  - 定时任务列表、创建/编辑/删除
  - 激活/停用、立即执行、执行历史
  - 任务类型、调度器状态、暂停/恢复
  - 消息模板
- **统一群发**：跨渠道的群发能力（与微信/企业微信群发对应）
- **顺序定时群发（滴灌式）**：见「微信管理」；支持时段/发送日、断点续传、成功后打标签并写回本地好友目录
- **商家信息定时发送**：第三方集成场景下的商家信息定时发送（如商户排班等）

---

## 十一、订单与客户管理

- **客户管理**
  - 客户列表、搜索与筛选（关键词、状态、地区、公司、订单数、金额等）
  - 客户详情、新建/编辑
  - 客户维度统计
- **订单管理**
  - 订单列表、筛选、排序
  - 订单详情、新建/编辑订单
  - 订单状态、支付状态、支付方式等
  - 拼多多等订单导入（CSV）、导入结果反馈
- **权限**：通过 `order:read` / `order:write` / `order:delete` 等控制

---

## 十二、系统配置与运维

- **系统管理**（需 system:admin）
  - 系统信息、运行统计
  - 配置项 CRUD、校验、导入导出、历史、重置、模板
  - 系统监控：性能指标、健康状态、指标历史、预警
  - 日志：日志配置、文件列表、查询、分析、导出
  - 备份：创建备份、备份列表、详情、删除、恢复、校验
  - 系统任务：任务列表、创建、执行、取消、运行中任务
  - 维护模式、缓存清理、缓存信息、数据库状态
- **外部 API 配置**
  - 外部 API 配置的创建/编辑/启用禁用
  - 测试调用、配置列表与筛选

---

## 十三、统计分析

- **运营总览**：概览类统计（部分版本）
- **回复命中率统计**：关键词/FAQ/大模型命中与趋势
- **热门问题排行**：高频问题统计
- **报表与仪表板**（部分版本）：自定义报表、仪表板、导出
