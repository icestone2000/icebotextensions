# 智能客服/机器人系统 — 特色功能（客户推广版）

---

## 一、大模型会「动手」：工具调用

### 1.1 大模型调用工具发通知

- 大模型在对话中可**调用「发送通知」工具**，向指定微信/企业微信用户或群组发送消息。
- 支持个人微信、企业微信；未指定接收者时可按当前会话发送。
- **场景示例**：用户说「帮我提醒一下张三明天开会」→ 大模型解析后调用工具给张三发提醒；或对当前群发一条通知。

### 1.2 大模型参与规划定时任务

- 大模型可调用**「创建群发配置」工具**，创建定时群发任务（每天/每周/每月/指定日期、发送时间、目标群组、消息内容等）。
- 系统按配置在指定时间执行发送，实现**「大模型规划、系统执行」**的定时触达。
- **场景示例**：用户说「每周一早上 9 点给所有客户群发本周活动」→ 大模型创建群发配置，系统按时执行。

### 1.3 其他可调用能力

- 创建/更新/查询订单、添加订单项、发送媒体、更新客户备注、Python 代码执行等，便于大模型在对话中完成查单、改单、通知、备注等操作。

## 二、回复更聪明：先本地后大模型

### 2.1 先匹配本地，再调大模型

- 回复链路：**关键词匹配 → 常见问题(FAQ) 匹配 → 大模型回复**。
- 能命中关键词或 FAQ 的**直接本地回复**，不调用大模型，**响应更快、成本更低**。
- **价值**：常规问题用本地解决，大模型只处理复杂/开放问题，节省调用、提高首包速度。

### 2.2 多条用户消息合并后一次回复

- 同一会话、同一用户在一定时间内的多条消息会**先合并**再交给大模型，大模型**只生成一条回复**。
- 可配置「多条消息合并等待秒数」（如 3 秒）；设为 0 表示不合并。
- **价值**：避免用户连发多条时机器人连回多条，减少冗余、更像真人「看完再说」的习惯。

### 2.3 简短口语化，更像真人

- 通过提示词模板统一要求：回复**简短、口语化**，少用「您好」「感谢咨询」等套话，一两句能说清就不长篇大论。
- **价值**：整体风格更接近真人客服/卖家，降低「一眼看出是机器人」的感觉。

## 三、人机协同：真人优先、一句接管

### 3.1 真人客服名单 + 等待时间

- 可配置**真人客服列表**（微信名/ID）：这些账号发的消息**不触发**自动回复，避免抢话。
- 可配置**真人客服等待秒数**：机器人准备回复前先等待该秒数；若在此时间内**真人客服或当前账号**已回复，则**取消**机器人回复，仅真人未回复时才由机器人发送。
- **价值**：优先给真人应答机会，机器人作兜底，适合「人机协同」值班。

### 3.2 聊天命令随时人工接管

- 支持配置**人工接管命令**（如「人工接管」）：在会话中发送该命令即可**切换自动回复开/关**。
- 可配置关闭/开启时的提示语（如「人工已接管，机器人自动回复关闭！」）。
- **价值**：无需进后台，在聊天窗口用一句话即可随时接管或交回，适合值班切换、突发客诉。

## 四、知识可沉淀：从对话到知识库

### 4.1 从聊天记录抽取知识

- 支持**从聊天记录抽取问答对**并导入为 FAQ：按时间范围、账号、群组筛选记录，由大模型抽取「问题-答案」对，勾选后**一键导入**常见问题库。
- **价值**：把历史对话沉淀为可复用知识，方便冷启动与持续优化。

### 4.2 从文本抽取 FAQ

- 支持**从任意文本**（文档、说明、粘贴的聊天记录等）抽取问答对并导入 FAQ；长文本自动分批调用大模型。
- **价值**：产品文档、培训材料、历史记录等均可快速转为知识库条目。

### 4.3 群组/商品知识库

- 可为群组或闲鱼宝贝配置**知识库/商品描述**，大模型回复时会结合该上下文，保证话术与产品一致。

## 五、多端与运维

### 5.1 手机浏览器即可配置

- 管理后台为 Web，已做**移动端适配**（viewport、响应式布局、小屏样式），**支持在手机浏览器中登录并配置**机器人、群组、关键词、FAQ、大模型等。
- **价值**：外出或值班时也可随时调整配置、查看状态。

### 5.2 多通道一致体验

- 支持**个人微信、企业微信（iPad 协议）、闲鱼**；智能客服配置（关键词、FAQ、大模型、提示词）**共用**，按群组/宝贝开关与参数即可区分策略。
- 真人客服、人工接管、消息合并等能力在微信、企业微信、闲鱼侧逻辑一致，一套能力多端复用。
